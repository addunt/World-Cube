# 自然奇境：第二套六面魔方

状态：待评审。本文件只记录已批准的设计。评审通过之前不写实现计划，不改运行代码，不部署。

## 决定

在现有低多边形程序化魔方上增加一整套六个自然奇境。页面默认显示这套新场景。原版六面保留，可整套切换，用来对照。几何、地面像素、时间动画、九格裁切、旋转时的重力和切向、贴地看、时间轴和层控件都沿用现在的框架。

两套都是六面完整生境，不是把旧模型换色，也不是在一个魔方上混放两套地标。新场景不使用外部生图模型、导入网格或视频贴图。

## 不包含

- 解谜关卡、胜负、积分、账号、后端和存档
- 第七个面、新的魔方阶数或新的渲染器
- 为新套装重做音轨，或把原版 `gravity-foley.flac` 配到新画面上
- 修改 MIT 许可、删去原作者署名，或写入使用者的真实姓名
- 改写原版六个生境的坐标、调色和文案

## 框架里哪些东西不动

这些文件的原版几何与契约保持不变：`ground-valley.js`、`ground-water.js`、`ground-night.js`、`cube-state.js`、`habitat-renderer.js`。新景物使用它们已经提供的能力。

| 已有能力 | 新套装怎么用 |
| --- | --- |
| `b.box`、`b.ell`、`b.branch`、`b.face`、`b.pixel`、`b.rnd`、`b.static` | 只靠这些图元搭建 |
| 整面坐标 X、Y ∈ [-1.5, 1.5]，高度 +Z | 先画平面，再长高度 |
| `partition` 在 `x = i±0.5`、`y = j±0.5` 裁成九格 | 作者不手工切格；跨格的屋脊、桥、朽木、熔岩沟和风车叶片由裁切产生接缝 |
| `CubeState.groundFrame` | 转动中的位置、法线和重力继续交给它 |
| `GroundSurfaces.get(id)` 的 240×240 像素地面 | 每个新 id 增加一个分支；原有六个分支的公式不改 |
| `GroundCamera.habitat` 与贴地看 | 新镜头只调用现有相机，不新写投影 |
| 19.2 秒时间轴、层按钮、拖动拧层、空白环绕、WASD | 交互种类不增加 |

现有测试把 `CubeHabitats.scenes` 固定为长度 6，并要求每个生境九格都有多边形、高度 `0 ≤ h < 1.45`、最低点 `< 0.065`、最高点 `> 0.85`、至少五档高度、横竖方向都有接缝，而且 `t = 0.36` 与 `t = 2.81` 的活动几何不同、同一时间可复现、`static` 不随时间变化。因此：

- `CubeHabitats.scenes` 继续只导出原版六景。现有 14 项测试不改断言。
- 新套装放在新增的 `CubeHabitats.suites.natural`。
- `CubeHabitats.suites.original.scenes` 与 `CubeHabitats.scenes` 是同一份原版列表。
- 页面默认读取 `natural`，不把 `scenes` 当作默认画面。
- `model(id, t, staticPass)` 对原版 id 和新 id 都可用。原版 id 的调用方式不变，现有测试不必传入套装名。

新 id 为 `snow`、`oasis`、`bamboo`、`firefly`、`volcano`、`island`。它们不得与 `reef`、`autumn`、`lake`、`marsh`、`root`、`kelp` 重名。`cube-habitats.js` 和渲染器的 static 缓存都以 id 为键；重名会把两套网格串在一起。

## 面与地标

面名仍是 `PY`、`PZ`、`PX`、`NX`、`NZ`、`NY`。套装只更换「贴纸面 → 生境 id」的表、文案、地面、几何和镜头。

| 面 | id | 名称 | 界面强调色 | 地标 |
| --- | --- | --- | --- | --- |
| `PY` 顶 | `snow` | 雪山温泉 | `#9fd4e0` | 跨过 `x = -0.5` 的雪檐木屋，屋前温泉 |
| `PZ` 前 | `bamboo` | 竹林溪谷 | `#3f8f5a` | 跨过 `x = 0.5` 的石桥 |
| `PX` 右 | `oasis` | 沙漠绿洲 | `#d89a3c` | 泉边棕榈；一株树干跨过竖向格线 |
| `NX` 左 | `island` | 云上海岛 | `#8eb8d6` | 风车；叶片在转动中越过一条格线 |
| `NZ` 后 | `volcano` | 火山熔岩 | `#e25b2a` | 黑岩尖峰；熔岩沟跨过 `y = -0.5` |
| `NY` 底 | `firefly` | 萤火湿地 | `#d2e38a` | 跨过 `x = -0.5` 的朽木，青蛙在近端 |

每个新生境都要满足原版测试已经编码的高度契约：有贴地的顶点（`< 0.065`），也有高于 `0.85` 且低于 `1.45` 的顶点。瀑布、热气和火星不得钻进壳内，所有几何高度保持在这个区间。

水陆或岩流分界使用 `GroundNatural.surface(id, x, y)`。正值是岸、雪地、沙地、草岛或岩壳，负值是泉、溪、浅水、岛外或熔岩沟。地面上色和物体落点使用同一个函数。

### 雪山温泉

冷色雪地和岩石，木屋用深木色，泉水是单独的暖青绿，不借用枫溪木屋的秋橙。木屋中心在 `(-0.55, 0.15)`，屋檐沿 X 宽于 `0.2`，因此跨过 `x = -0.5`。雪脊斜穿九格。泉池中心在 `(0.15, -0.35)`，半径 `0.42`，压过中心格线。木柱插进雪里，池边有石头。热气从泉面沿 +Z 上升并变淡；雪花在 XY 上飘，再落到雪面附近。热气和雪花是这一面的两个运动。低机位要同时看见屋柱和雪。

### 沙漠绿洲

沙金和赭石是主色，泉是深青，棕榈是暗绿，骆驼是浅褐。这些颜色不重复珊瑚礁或暮色湖湾。新月形沙丘包住位于 `(0.2, -0.55)` 的泉池。三株棕榈站在近岸，其中位于 `(0.55, -0.25)` 的树干跨过 `x = 0.5`。骆驼在 `y = -0.15` 的沙路上沿 X 缓行，身体跨过 `x = 0`。棕榈根扎在湿沙里，骆驼脚落在路上。风沙贴着沙丘在低高度流动；骆驼的位移比风沙慢。这是两个运动。低机位看见树干和腿。

### 竹林溪谷

竹绿、石灰和水青，熊猫只使用黑与近白。溪流中心线随 Y 弯曲，和枫溪不是同一条河。石桥桥面从负 X 伸到正 X，并跨过 `x = 0.5`；桥台落在两岸。两岸是竹丛，熊猫在近岸桥阶旁边。桥柱进入溪水，竹根张开，熊猫四足落在石上。竹梢以小角度摇摆；竹叶落到溪面后沿溪流漂移。低机位看见桥底和竹根。

### 萤火湿地

这一面不是白鹭月汀换色。画面里不放白鹭、月亮和作为主体的莲花。浅水占大部分格子，芦苇成丛，朽木从 `(-0.9, 0.2)` 到 `(0.4, -0.3)`，跨过 `x = -0.5`。青蛙在朽木近端。主色是暗水绿、枯苇和朽木褐，萤火是偏黄的绿，界面强调色用 `#d2e38a`，避开原版湿地的 `#a6ccaa`。朽木和青蛙都要有可见的接触。萤火沿重复的闭合路径飞。每个周期青蛙从浅水落到朽木近端一次，落地时水面在 XY 上扩出一圈涟漪。低机位看见朽木和蛙足。

### 火山熔岩

玄武岩黑、冷却壳和熔岩橙黄。没有原版对照面。火山口环绕 `(0, 0.25)`，外半径 `0.7`。熔岩沟从 `(0.1, -0.2)` 延伸到 `(0.15, -1.2)`，跨过 `y = -0.5`。黑岩尖峰在 `(-0.75, 0.55)`，顶部高于 `0.85`。尖峰根部接在岩壳上，沟有两岸。岩浆用沿沟移动的明暗表示流动，不做流体模拟。火星和烟从山口沿 +Z 升起。低机位看见沟岸和尖峰根。

### 云上海岛

草岛、土色岛腹、浅云、木色风车和浅色瀑布。它不是水母林。草岛是中心 `(0, 0.1)`、半径 `1.0` 与 `0.75` 的椭圆，盖住中部格子。岛腹向下收到贴地的岩石，因此侧面能看见岛是浮在云上的，同时高度仍 ≥ 0。风车轴在 `(0.45, 0.35)`，位于椭圆内部；叶片长 `0.55`，旋转时越过 `x = 0.5`。瀑布从岛缘 `(-0.2, -0.63)` 落到石台，落差用减小的 Z 表示，终点 ≥ 0.05，不进入魔方内部。云在岛腹周围的低高度沿 XY 漂移；风车绕自己的轴转动。低机位看见岛腹、瀑布落点和风车柱。

## 切换套装时什么保留、什么清掉

切换是整套替换，规则只有这一条：

1. 取消未完成的层动画和相机动画，停止播放。
2. 丢掉撤销历史，贴地看改为关闭。
3. 魔方回到该套装的对齐初始状态，和按下「复位」之后的物理状态相同。不把上一套的拧动结果套到新景物上。
4. 演示时间回到 0 并暂停，然后进入与页面第一次加载相同的手动观察。
5. 相机使用目标套装在 `t = 0` 的镜头。不保留上一套的方位角、贴地距离和环绕偏移。
6. 检查器、缩略图和强调色只显示当前套装的六景。缩略图按现有 `thumbnail()` 重画。

「复位」只重置当前套装，不改变套装选择。

两套的时长都是 19.2 秒。下面六段层动作的起止时间和 `axis`、`layer`、`dir` 与原版相同，因此对齐之后把时间轴拖到同一时刻，物理拧层相同，景物和镜头各自不同：

| 起 | 止 | 动作 |
| --- | --- | --- |
| 2.48 | 3.22 | `x` 层 `+1`，方向 `+1` |
| 3.46 | 4.17 | 同一层反向 |
| 7.08 | 7.78 | `y` 层 `0`，方向 `-1` |
| 8.10 | 8.80 | 同一层反向 |
| 12.10 | 12.80 | `z` 层 `-1`，方向 `-1` |
| 13.12 | 13.82 | 同一层反向 |

原版的 `shots` 和 `cues` 一字不改。自然奇境另备镜头表和中文提示。提示只描述该次拧动实际带走的新景物，不复用「礁鲨」「沉木」等原版句子。镜头时间单调并覆盖 `[0, 19.2]`。六个生境各有至少一个 `GroundCamera.habitat` 镜头；雪山、竹林、云岛、湿地这四镜的 altitude 不大于 32 度，用来看接触。开头和结尾是全景。每个层动作的中点要看见正在转动的那一块地面，以及贴在它上面的固定物和至少一个活动粒子。切换本身不继承当前时间；用户若要对照同一秒，先切换，再把时间轴拖到该秒。

`?suite=original` 在首帧之前选中原版。`?suite=natural` 或不带该参数时选中自然奇境。其他值也选自然奇境，页面不抛错。`?export=1` 仍只隐藏控件。不带套装参数的导出将录到自然奇境；导出原版画面必须加 `?suite=original`。自然奇境导出不混入原版拟音。

## 控件不盖住魔方

套装是检查器顶部的两段按钮，文案是「自然奇境」和「原版六面」，放在场景标题之上。当前套装使用 `aria-pressed="true"`。按钮在文档流中，不放进 `.stage`，也不使用会盖住画布的固定定位。

宽度不超过 765px 时，舞台仍在检查器上方，高度维持 `min(110vw, 510px)`。顶栏维持现在的 60px，套装按钮不塞进顶栏。拧层、六格缩略图、贴地看和时间轴都留在舞台下面。六个新名字都是四个字，继续使用现有的一行六列缩略图。无 WebGL 时，套装按钮和现有的播放、拧层、贴地看一起禁用。

## 确定性与缓存

新代码不得调用 `Math.random`。树枝、沙粒、雪花相位和萤火路径使用 `b.rnd(整数种子)`。活动几何只由生境 id 和时间 `t` 决定；同一 id 和同一 `t` 连续调用，顶点相同。

房屋、地形、桥、火山口、岛腹和风车柱放进 `b.static`。雪、风沙、骆驼、竹叶、萤火、青蛙、涟漪、岩浆明暗、火星、烟、云和风车叶片放在 static 之外。骆驼沿沙路缓行，青蛙每个周期从浅水落到朽木，二者都随 `t` 改变顶点，不得放进 static 缓存。static 缓存继续只按 id 存储，并且缓存 `t = 0` 的固定网格。`model(id, 0, true)` 与 `model(id, 任意时间, true)` 必须相同。切换套装不删除另一套的缓存，也不用一个 id 覆盖另一种网格。渲染器里按 id 和 `t` 保存的活动网格沿用这个隔离方式。

## 性能

下面两条是目标，不是已经测得的结果。规格里不写三角形数量或帧时间的达标数字。

几何目标：同一次 Node 测试里，先统计原版六个 id 在 `t = 0` 的 static、`t = 0` 的活动网格和 `t = 5` 的活动网格。统计口径是三角形数。`n` 个顶点的多边形分成 `n - 2` 个三角形；渲染器再把每个三角形写成 3 个顶点，所以 `habitat-renderer.js` 里的 `3 * (顶点数 - 2)` 是提交顶点数，不拿它当三角形数。1.5 倍只比较两侧用同一口径算出的三角形数合计。每个新 id 在相同时间和通道上不得超过这次运行测得的原版最大值的 1.5 倍。超过就减几何，不把倍数改大。

帧时间目标：在同一浏览器、同一台机器、1280×800 下，对两套各走一遍相同路径：加载、一次 +90° 层旋转、空白处环绕、选中一个生境、打开贴地看。自然奇境的帧间隔中位数不超过该次运行中原版中位数的 1.5 倍。样本不稳定时记下样本，单帧不算通过。这个目标不写进 CI 的固定毫秒阈值。

## 验收

实现完成时要留下这些证据，而不是在本文件里预填结果：

- 六个对齐面的静帧，能辨认各自的地标、跨格接缝和独立配色
- 六个动态：热气与雪、风沙与骆驼、竹梢与漂叶、萤火与涟漪、岩浆明暗与上升的火星或烟、云与风车
- 在当前套装内拧一层，使不同生境的地块混到同一面；另一套装的 id、网格和地面不得出现。撤销这次拧动后，地块回到拧动前的面、朝向和高度，接缝重新合上
- 桌面拖动拧层和空白环绕
- 390×844 的手机布局：舞台在上、控件在下，触控能拧动一层
- 切回「原版六面」后，复位状态仍是现在的晴海珊瑚、枫溪木屋、暮色湖湾、琥珀沉木、白鹭月汀、水母夜航
- `node --test` 的现有 14 项全部通过
- 新增测试通过：新六景的九格、高度、接缝、活动几何可逆、static 不随时间变化；原版 id 的 static 签名在生成新 id 之后不变；新文件源码不含 `Math.random`；几何目标用当次测量比较
- 最后在功能分支的 Vercel 部署上试玩。该部署必须包含现有的 `vercel.json` 和新套装

## 部署边界

当前公开地址 https://world-cube.vercel.app/ 是功能分支的生产部署，不是 `main`。`main` 没有 `vercel.json`，也没有这套新场景。后续若要更新试玩，只从含有静态构建配置和新套装的功能分支创建部署。不得用 `main` 覆盖这个生产地址。本设计轮次不创建部署。

`vercel.json`、`package.json` 和两条构建约定保持现状：安装命令为空，构建命令是 `rm -rf dist && node scripts/world-cube.cjs deploy`，输出目录是 `dist`，Node.js 为 `22.x`。新文件放在 `scene-cube/assets/starter/` 后，由现有的 deploy 复制进 `dist/`。
