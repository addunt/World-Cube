状态：主题与质量方向已确认；本详细规格待用户 review。未经确认，不实施、不写实施计划、不提交、不部署。

## 1. 目标与取舍

新增完整套装 `fantasy`，保留 `original`、`natural` 及其既有模型、纹理、镜头和交互。不是旧六景改色：六面分别使用蘑菇伞群、洞窟晶簇、断裂石环、树屋书架、星砂泉涡、盘卧幼龙六种主轮廓。

采用方案：代码图元建模、240×240代码纹理、固定结构加显著运动。相比只做纹理/粒子换色，这能保证主体差异；相比全场景高密度动画，可保留手机预算。无需新增渲染器、灯光系统或物理系统。发光感只用明暗色块和少量透明面，不依赖 bloom。洞窟采用敞口剖面，不用封顶遮住内部。

不包含任务、战斗、积分、账号、音轨制作、外部生图、外部模型、视频贴图和新投影。仍是可拧层、可环绕、可贴地看的互动生境。

## 2. 公共坐标与集成契约

- 整面 X/Y 范围 `[-1.5,1.5]`，+Z 为离开地表的局部高度。描述中的前景为负Y、后景为正Y，不代表屏幕方向。
- 全部几何 `0 ≤ Z < 1.45`；每景最低点 `<0.065`，最高点 `>0.85`，至少五档高度。浮空物必须有岛腹/支撑的视觉解释，不能把“浮空”实现成负Z穿壳。
- 仅用现有 `box/ell/branch/face/pixel/rnd/static`；多边形保持凸且共面，复杂面拆三角形。全部整面建模，由 `partition` 自动裁九格；不在模型里手切方块。
- `groundFrame` 决定位置、切向、法线和重力，转层时固定物、活动物、地面一起转；不添加屏幕空间悬浮装饰。
- 设计模块职责为 `GroundFantasy.draw(id,b,t)` 与 `GroundFantasy.surface(id,x,y)`；此为将来接口约定，不是本阶段实现指令。surface为正表示实体地表/岸/冰岩，负表示泉水、溪水或空隙底色。它是纹理和物体落点共同依据；另有抬升平台时明确平台高度，不把surface当高度函数。
- `CubeHabitats.scenes` 仍只表示原版六景；新增登记在 `suites.fantasy`。每个id可直接经既有 `model(id,t,staticPass)` 访问，不依赖当前全局套装。

## 3. 六景详细构图与运动

以下运动在普通动画模式按绝对秒数t运行；`q=(t mod P)/P` 表示周期相位。暂停或减少动态模式允许静止，主动寻址仍返回该时间的确定姿态。表中镜头角度是局部azimuth/altitude，不是新相机算法。

### 3.1 月光菌林

**构图。** 靛蓝腐殖地，青紫伞盖和乳白菌褶，浅溪沿 `x=0.20+0.12 sin(2y)` 贯穿Y，半宽0.14。主菌柄中心 `(-0.55,0.30)` 从Z=.02升至.85，伞盖半径.45、顶部1.13，底面菌褶以8根放射条表现。另两株高度.55/.72，位于 `(.80,.75)`、`(-1.03,-.78)`。前景 `(.50,-.65)` 布置4株.12–.27幼菌，地表菌根连向主柄。后侧扁月石仅高.45，不画第二个遮挡主体的巨大月盘。大菌伞不盖住前景溪道。

**动态A：巡游月蛾。** 3只蛾沿溪前方的椭圆闭路飞，路径中心 `(.15,-.35,.58)`、XY半径.75/.40、Z振幅.16，周期6秒；双翼展宽.16–.22，以周期.8秒开合，开合角总范围至少70°。最低飞行高度.28，不穿菌柄；路线上避开三株菌的实体包络。

**动态B：成束孢子升降。** 8个孢子沿主伞前外沿上升，起点Z=.28、终点1.25，周期4秒，单体半径.025–.04；经过最高点后在透明度接近零时回到起点，至少三个不同相位。不是仅靠微小亮度变化。明暗菌褶可辅助呼吸，但不计作第二动态。

**证据。** 默认角度 `(18,36)`：看见主伞、菌柄前侧、月蛾和孢子通道。贴地角度 `(30,26)`：看见根系入土、溪岸、幼菌；`t=.5/2/3.5` 对比蛾位移与孢子升高。跨格检查主伞在x=-.5处有高于.80的配对切口。

### 3.2 水晶洞窟

**构图。** 洞是后侧开口马蹄岩壁：沿Y=.65–1.25布置深蓝岩块，峰高1.22；前方Y<.1不建洞顶或高墙。中央浅水池椭圆中心 `(.05,-.15)`、半径.65/.42。主晶簇 `(-.65,.30)` 高1.12，5根六棱晶柱高低错开，晶柱从石座.06长出；右前有高.42的小晶簇。晶桥从 `(.20,-.10,.16)` 到 `(.85,-.10,.32)`，宽.15，跨x=.5并落在两岸石座上。色块用深蓝岩、冰青、淡紫三组，不复制冰龙雪白调色。

**动态A：悬晶回转。** 池前上方中心 `(.10,-.38,.64)` 放两根悬晶，长.30、宽.10；周期5秒绕共同中心作半径.22的水平公转，同时自身绕+Z转动，Z起伏±.10。轨道最高点<.95，与桥和晶簇保持.08间距。

**动态B：水面光环扩散。** 3圈实体薄环从池心扩张，半径.08→.48，周期2.4秒，相位均分；环带宽.025，高Z=.025，轮廓明亮且随半径增长变淡。环不越过岸线，超岸的局部不绘制。背景光线闪烁可作补充，但不作为唯一运动。

**证据。** 默认 `(-16,38)`：晶簇、悬晶轨道和池面同时露出；贴地 `(15,25)`：晶根与石座、桥脚接岸可见。`t=0/1.2/2.4` 展示悬晶明显换位及环扩张；高位晶桥切口Z>.15。

### 3.3 浮空遗迹

**构图。** 赭灰石与失绿青苔；三座有收尖岛腹的石台中心分别 `(-.70,.20,.30)`、`(.45,.35,.42)`、`(.15,-.75,.20)`，顶面半径.48/.42/.30，岛腹最低Z=.04，背景地面为低云纹理而非复制云岛风车。主断石环中心 `(.45,.35)`，环平面在XZ，底Z=.43、顶1.25、外宽.80；环断口位于左上，占圆周约1/5，不能闭成完美圆环。前景两级断阶从Z=.04通至.20。远处两根残柱高.65/.90，不遮断口。

**动态A：断石回旋。** 三块边长.10–.16的方石沿断环前侧闭合椭圆轨道运动，中心 `(.45,.08,.76)`，X/Z半径.38/.27，周期7秒；全轨迹Z≥.49，避开实体环，至少一块在前景可读。方石自身缓转，不能只转对称球体。

**动态B：布幡摆动。** 前台 `(-.70,.05)` 立高.80的旗杆，旗面长.36高.20，沿X伸展，用3段凸四边形；周期2秒，自由端Y摆幅±.10、Z起伏±.04，固定端与旗杆保持连接。旗始终与石环不同色且不被柱遮住。

**证据。** 默认 `(22,35)`：断口和两组运动都可见；贴地 `(34,24)`：岛腹、阶梯最低点、旗杆脚可见。`t=0/1.75/3.5` 记录石块绕行，`t=.5/1.5` 记录幡两端相反摆位。石环跨x=.5切口高于.70。

### 3.4 巨树书屋

**构图。** 大树不是普通树换色：主干中心 `(-.48,.28)`，根展半径.50，干顶1.25，树冠集中Y>.35和Z>.95，留出前侧窗口。两层木平台在Z=.35/.72，宽.85、深.55；屋体中心 `(-.35,.10,.60)`，开口朝负Y，门窗浅金。外墙前沿布置两组彩色书脊，单本有厚度且不使用可读小字。前景从 `(.55,-.75)` 的石阶经小桥连接平台。平台不能挡住根系证据区 `(-.90,-.10)`。配色铜棕、苔绿、纸页米白。

**动态A：飞书绕屋。** 2本展开的书沿前侧宽椭圆飞行，中心 `(.20,-.38,.60)`，XY半径.55/.26、Z振幅.12，周期6秒；每本宽.20，高.10，书页夹角按周期1.5秒在45°–115°变化。整条轨道避开屋墙与树干，不穿根和桥。

**动态B：门前吊灯摆动。** 悬挂点 `(-.05,-.28,.96)`，绳长.23，灯体宽.10高.13；周期2.8秒绕悬点摆±25°，灯底始终>.50。绳与灯同步变换，不能灯动而绳脱离。树叶微晃只作附加。

**证据。** 默认 `(12,37)`：书架、屋门、飞书页和吊灯均无遮挡；贴地 `(25,25)`：根须入土、石阶/桥台接地。`t=0/1.5/3` 对比飞书，`.7/2.1` 对比吊灯左右极值。平台或根跨x=-.5有Z>.20的配对切口。

### 3.5 星砂秘泉

**构图。** 靛紫砂地上布金白星砂，独立于沙漠绿洲：不放棕榈和骆驼。泉心 `(.10,-.20)`，椭圆半径.72/.60，水面Z=.025；石环在半径.80/.68处以12块厚石围成，顶Z=.13。后侧 `(-.75,.70)` 是高1.12的分叉星石，顶端五角星以凸三角形组合，不能把凹星面直接扇形剖分。右侧有三级砂丘最高.48，前景一条窄踏石道通向泉沿，泉口石环跨y=-.5。

**动态A：泉上星砂旋带。** 16颗星砂粒形成两条螺旋弧，围泉心转，XY半径.18–.55、Z=.10–.65，单粒尺寸.035–.055；周期5秒，XY绕行与Z升降连续。末端粒子淡出后回到低点，不能高速闪现；至少四颗在任一正常时刻清楚可见。

**动态B：星石摆锤。** 星石右叉的支点 `(-.57,.67,.94)` 悬一枚长.20、宽.11的菱形石，绳长.21，周期3秒摆±30°；最低点>.45。与前景旋带空间分离，不把两组都做成同一片粒子。水面两条亮弧可辅助转动但不计第二运动。

**证据。** 默认 `(-18,39)`：看见水面旋带、后侧摆锤与踏石；贴地 `(10,26)`：池岸石底、踏石与水面高度差。`t=.75/2.25` 检查摆锤极值，`t=0/1.25/2.5` 检查旋带上升和换位。泉环跨y=-.5切口Z>.06。

### 3.6 冰晶龙巢

**构图。** 冷白冰岩、浅蓝龙身、深靛角爪和暖琥珀眼。巢心 `(.05,-.10)`，冰环外半径.76、顶高.16；盘卧幼龙由低多边形椭球躯干、分段尾、四足、折翼、长颈头部组成，不用一条蛇替代。身体中心 `(-.12,-.02,.30)`，头朝前右，头中心 `(.43,-.45,.52)`；前足压在巢台.10上，尾从后侧弯至 `(.75,.10,.22)` 跨x=.5。后侧冰尖最高1.20但避开头部投影；三枚卵位于 `(-.65,-.55)`、顶高.28。

**动态A：幼龙呼吸与尾摆。** 躯干仅上表面随周期3秒升降.04，支撑足与巢接触点不动；尾尖围尾根缓摆，XY位移总幅度≥.22，周期4秒，分段插值保持相连。尾摆是主要肉眼运动，细小呼吸不单独计入两动态。

**动态B：鼻前冰息。** 从 `(.64,-.56,.54)` 朝负Y/正Z发出5–7片多边形冰羽，喷吐周期4秒；每周期前1.8秒推进，路径总长.55、高度增加.18、宽由.04扩至.16，后.7秒淡出，其余时间停息。冰羽起点随头保持连接，不是不可见细雾；不遮住整张龙脸。不得复用原版拟音。

**证据。** 默认 `(28,36)`：头、眼、前爪、尾尖与冰息方向清楚，后冰尖不挡龙；贴地 `(40,24)`：前爪/卵/巢环接触可见。`t=.5/1.5/3` 对比喷吐/停息，`t=1/3` 对比尾尖极值。龙尾或巢环跨x=.5的高位接缝必须重合。

## 4. 肉眼可辨的质量门槛

以上尺寸和周期是必须实现的设计下限，不以“顶点不同”代替可见运动。不得把主动态缩成几粒不足一个像素的亮点，也不以仅改颜色交差。

- 在1280×800桌面与390×844手机页面，以正常选景完成fit后的真实舞台大小检查；浏览器不放大，不靠贴地才能识别。主体投影包围盒宽度至少占舞台宽的18%，最短可辨动态实体或运动带厚度至少3 CSS px。
- 每景两类主动态分别在≤4秒连续观察内可辨（冰息从喷吐开始计；其余从任意正常运动相位计）：至少一个特征点位移≥8 CSS px，或具备实体轮廓的开合/摆动跨越≥15°且外缘位移≥8 CSS px。两个条件按每类动态分别验收，不能一类通过替另一类通过。
- 若完整构图fit后达不到门槛，优先调主体位置、尺度、对比色、轨迹方向与镜头；不以裁掉魔方、提高渲染分辨率、全局放大或越过几何预算补救。
- 默认镜头的两类动态和主体关键部位至少80%的对应观察时段无遮挡；定量投影/射线辅助与实际连续视频都需留存，不能只有对称几何旋转的数值证明。

## 5. 相机、手机与层动画

各景角度为初始设计姿态；普通选景使用既有投影fit机制对当前完整魔方及邻面动态包络构图。允许在不改变上述可见性证据的前提下微调azimuth≤10°、altitude≤5°；更大调整需更新设计并review。zoom与focus由真实舞台投影确定，不写死“某个zoom必过”。贴地采用表内局部角度、沿用既有相机接口，近看允许邻面离框，但主体接触点不得被近裁或内部壳遮住。

- 桌面1280×800、手机390×844与横竖切换均检查。正常选景完成后，壳体及全部生境几何在舞台内留至少8 CSS px边距，下方状态文案另留24px，不被控件遮盖；控制区处于文档流，手机舞台上、控件下。
- 动态包络必须覆盖本组六景完整轨迹，不可只给新id套现有有限采样后便宣称所有时间安全。对解析上下界或覆盖整周期的保守包络进行验证；采样仅是回归证据而非数学保证。不得每帧重建包络。
- resize在相机/转层中发生时合并为pending，二者都结束后针对最新尺寸、已提交cubies补fit一次；退出该模式、切换套装、贴地、reset、进入演示要清理过期工作。环绕和WASD保留用户控制，不逐帧强拉回镜头。
- 沿用19.2秒演示及原有六段拧层时刻/动作，原版和natural镜头不改。本组开头/末尾全景；六景各有≥1个独立镜头，镜头时间单调覆盖全时段。三次成对层转中点要看见固定主体片段与至少一种活动几何同块转动，中文提示只描述实际被带走的本组景物。
- 每景另留贴地证据。普通fit通过不代表贴地接触通过，贴地通过也不代表手机完整构图通过。

## 6. 确定性、缓存、切换与导出

- 所有随机摆放只用固定整数种子的现有rnd。活动几何只由id和绝对t决定；不累积dt、不读真实时钟、不依赖上次调用和套装选择。跨周期重置发生在不可见/淡出阶段，不产生明显瞬移。
- 地形、屋体、晶柱、冰巢等放static，活动物在static外；static按id缓存规范t=0几何。同id `.36→2.81→.36` 签名一致，先在非零t请求static也与零时相同。
- 网格、240px纹理和构图包络按唯一id隔离；切换不清空另一套缓存、不把fantasy写入原有id。来回切换与混拼都不能串图。活动缓存保持现有有界替换策略，不能按所有历史t无限增长。
- 切换整套时停止播放，取消层转、相机与指针捕获，清撤销、贴地、选景跟踪和pending fit；对齐复位、时间归零并暂停演示，按既有减少动态偏好进入观察；初始镜头属于目标套装。reset不改变当前套装。
- 显式页面选择 `?suite=fantasy`，导出CLI应能显式 `--suite fantasy`，传递到加载URL；fantasy始终无音频流，拒绝带音轨参数，不混原版拟音。全局不带suite/无效值回退、套装顺序及默认入口以东方集成规格为准；本规格不覆盖它们。CLI的original显式配音能力保持。
